## EJERCICIO: CREACIÓN DE UNA WEB COMPLETA DE TURISMO RURAL

Proyecto práctico de HTML5 y CSS3 - Sin JavaScript

Objetivo: crear una página web completa para una empresa ficticia de turismo rural llamada Escapada Natural, utilizando HTML5 semántico y un archivo CSS externo.

## 1. HEADER

- Ocupará el 100% del ancho.

- Incluirá el nombre de la empresa, una frase descriptiva y una imagen o logotipo.

- Tendrá una altura aproximada de 180px.

## 2. NAV

- Se situará debajo del header.

- Incluirá los enlaces: Inicio, Alojamientos, Actividades, Galería y Contacto.

- Los enlaces no tendrán subrayado.

- Al pasar el ratón por encima, cambiará el color de fondo y el color del texto.

- El cursor deberá mostrarse en forma de mano.

## 3. MAIN

- Será la zona principal de la página.

- Tendrá un ancho aproximado del 70%.

- Dentro del main deberán aparecer varias secciones.

## SECCIÓN 1 - Presentación

- Un título.

- Dos párrafos explicando los servicios de la empresa.

- Una imagen grande relacionada con turismo rural.

- La imagen tendrá un ancho máximo del 100%, mantendrá su proporción y tendrá bordes redondeados.

## SECCIÓN 2 - Alojamientos

Crear una sección con tres alojamientos diferentes. Cada alojamiento se mostrará dentro de <article> e incluirá:

- Una imagen.

- Nombre del alojamiento.

- Breve descripción.

- Precio por noche.

- Un enlace con el texto “Más información”.

- Los tres artículos deberán diferenciarse visualmente mediante borde, fondo o sombra.


## SECCIÓN 3 - Tabla de precios

Crear una tabla con la siguiente información:

| Alojamiento | Capacidad | Precio/noche | Desayuno |
| --- | --- | --- | --- |
| Casa del Bosque | 4 personas | 90 € | Incluido |
| Cabaña del Lago | 2 personas | 75 € | Incluido |
| Casa de Montaña | 6 personas | 120 € | No incluido |

- La tabla ocupará el 100% del ancho disponible.

- Tendrá bordes visibles.

- Utilizará border-collapse: collapse.

- La fila de encabezados tendrá un estilo visual diferente.

- Al pasar el ratón sobre una fila, deberá cambiar ligeramente de color.

## 4. ASIDE

- Se situará al lado del main.

- Tendrá un ancho aproximado del 30%.

- Incluirá actividades recomendadas, información sobre horarios y enlaces relacionados.

## Actividades sugeridas

- Senderismo.

- Rutas en bicicleta.

- Paseos a caballo.

- Visitas guiadas.

- Observación de aves.

## 5. GALERÍA DE IMÁGENES

- Crear una sección con una galería de al menos 6 imágenes.

- Las imágenes deberán estar guardadas dentro de una carpeta llamada img.

- Todas deberán incluir el atributo alt.

- Las imágenes deberán tener bordes redondeados, una pequeña sombra y efecto hover.

- Al pasar el ratón sobre una imagen deberá aumentar ligeramente de tamaño.

## 6. FORMULARIO DE CONTACTO

Crear una sección con un formulario que contenga:

- Nombre.

- Apellidos.

- Correo electrónico.

- Teléfono.

- Tipo de alojamiento mediante un .

- Fecha de entrada.

- Número de personas.

- Un área de texto para observaciones.

- Botón “Enviar solicitud”.

- Todos los campos deberán tener su correspondiente etiqueta .

## 7. FOOTER

- Ocupará el 100% del ancho.


- Incluirá el nombre de la empresa, dirección, teléfono, correo electrónico y texto de copyright.

## REQUISITOS CSS

El archivo CSS deberá estar separado del HTML.

Utilizar:

html { font-size: 20px; }

También:

## La página deberá utilizar diferentes tipos de medidas:

- px

- rem

- vh

## Propiedades que deberán aparecer en el CSS

- margin · padding · width · height · min-height · border · border-radius · background-color · box-shadow · text-align · display · inline-block · vertical-align · cursor · transition · hover

## El contenedor principal deberá:

- Ocupar aproximadamente el 90% del ancho.

- Estar centrado horizontalmente utilizando margin: auto.

- Mostrar main y aside uno al lado del otro.

## RESULTADO ESPERADO

La página deberá tener un diseño limpio y moderno, con colores relacionados con la naturaleza y todas las zonas claramente diferenciadas. No se utilizará JavaScript.
