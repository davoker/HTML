# JavaScript-Ejercicios de funciones

5 ejercicios sencillos de dificultad progresiva

## Ejercicio 1 - Saludo

Crea una función llamada **saludar()** que muestre en la página el siguiente mensaje utilizando **document.write()**: Hola, bienvenido a JavaScript Después, llama a la función para comprobar que funciona.

## Ejercicio 2 - Mostrar un nombre

Crea una función llamada **mostrarNombre(nombre)**. La función debe recibir un nombre como parámetro y mostrar un saludo con **document.write()**. Hola Patricia Llama a la función pasando un nombre como argumento.

## Ejercicio 3 - Sumar dos números

Crea una función llamada **sumar(numero1, numero2)**. La función debe recibir dos números, sumarlos y mostrar el resultado con **document.write()**. La suma es: 15

## Ejercicio 4 - Calcular el doble

Crea una función llamada **doble(numero)**. La función debe recibir un número y devolver su doble utilizando **return**. Después, guarda el resultado en una variable y muéstralo con **document.write()**. El doble de 8 es 16

## Ejercicio 5 - Calcular precio total

Crea una función llamada **calcularTotal(precio, cantidad)**. La función debe multiplicar el precio por la cantidad y devolver el resultado utilizando **return**. Después, guarda el resultado en una variable y muestra con **document.write()** el precio, la cantidad y el total. Precio: 20 € Cantidad: 3 Total: 60 €
