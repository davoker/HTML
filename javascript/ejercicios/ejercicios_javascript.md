## Ejercicios de JavaScript: Variables y document.write()

5 ejercicios progresivos - Enunciados

## Ejercicio 1 - Datos personales

- Crea tres variables llamadas nombre, edad y ciudad.

- Asigna un valor a cada variable.

- Muestra los tres datos en la página utilizando document.write().

Ejemplo de salida: Nombre: Laura Edad: 25 Ciudad: Gijón

## Ejercicio 2 - Datos de un producto

- Crea las variables producto, precio y cantidad.

- Asigna valores a las tres variables.

- Crea una nueva variable llamada total que calcule el resultado de multiplicar el precio por la cantidad.

- Muestra todos los datos y el total utilizando document.write().

Ejemplo de salida: Producto: Teclado Precio: 30 EUR Cantidad: 2

Total: 60 EUR

## Ejercicio 3 - Cálculo de edad

- Crea una variable nombre con el nombre de una persona.

- Crea una variable anioNacimiento con su año de nacimiento.

- Crea otra variable anioActual con el valor 2026.

- Crea una variable edad que calcule la edad aproximada restando el año de nacimiento al año actual.

- Muestra una frase completa utilizando document.write().

Ejemplo de salida: Ana nació en 1990 y tiene aproximadamente 36 años.


## Ejercicio 4 - Precio con descuento

- Una tienda tiene un producto llamado Monitor, con un precio de 200 EUR y un descuento del 15 %.

- Crea las variables necesarias para guardar esos datos.

- Calcula cuánto dinero se descuenta y guárdalo en una nueva variable.

- Calcula el precio final después de aplicar el descuento.

- Muestra el producto, precio original, porcentaje de descuento, cantidad descontada y precio final con document.write().

Resultado esperado:

Producto: Monitor Precio original: 200 EUR Descuento: 15 % Cantidad descontada: 30 EUR Precio final: 170 EUR

## Ejercicio 5 - Compra completa

- Crea las variables producto, precio, cantidad, descuento y gastosEnvio.

- Utiliza como datos: Portátil, 650 EUR, 2 unidades, 10 % de descuento y 15 EUR de gastos de envío.

- Crea nuevas variables para calcular: el subtotal, la cantidad descontada, el precio después del descuento y el precio final añadiendo los gastos de envío.

- Muestra todo el resumen de la compra utilizando document.write().

- Utiliza etiquetas HTML dentro de document.write() para organizar la información en varias líneas.

Resultado esperado: RESUMEN DE COMPRA Producto: Portátil Precio unidad: 650 EUR

Cantidad: 2

Subtotal: 1300 EUR

Descuento: 10 %

Descuento aplicado: 130 EUR

Gastos de envío: 15 EUR

TOTAL: 1185 EUR
